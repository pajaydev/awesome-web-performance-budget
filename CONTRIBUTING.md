# Contribution Guidelines

Please note that this project is released with a [Contributor Code of Conduct](code-of-conduct.md). By participating in this project you agree to abide by its terms.

## What belongs here

Entries must help people **set, enforce or monitor web performance budgets**. Please check that your suggestion:

- Is directly related to web performance (not general SEO, marketing or agency services).
- Is working, publicly reachable and not hosted on a temporary or preview domain.
- Has a free tier or free tool if it is a commercial product. Link to that free tool.
- Is not already on the list.

If you build or maintain the project you are adding, say so in the pull request description.

## How to add an entry

1. Fork the repo and create a branch.
2. Add one item per pull request, at the end of the most relevant section.
3. Use the format `- [Name](link) - Short description.` Keep the description to one sentence that ends with a period.
4. Follow the general [awesome list guidelines](https://github.com/sindresorhus/awesome/blob/main/contributing.md#adding-something-to-an-awesome-list).

**Working on your first pull request?** [How to Contribute to an Open Source Project on GitHub](https://egghead.io/courses/how-to-contribute-to-an-open-source-project-on-github) is a great tutorial by @kentcdodds.
